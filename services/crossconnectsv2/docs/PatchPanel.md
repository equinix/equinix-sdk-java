

# PatchPanel

The patch panel is a device which has a series of connector ports.  This device is to identify the source and destination location to connect. Patch Panel can be installed with a cabinet.

| Name | Type | Description | Notes |
|------------ | ------------- | ------------- | -------------|
|**id** | **String** | Patch Panel ID |  |
|**portA** | **BigDecimal** | Specify the desired port number for port A. When ports are not selected, next available ports will be used |  [optional] |
|**portB** | **BigDecimal** | Specify the desired port number for port B. When ports are not selected, next available ports will be used. If no selection is required, use value of &#x60;-1&#x60; |  [optional] |
